Steganography is the art of hiding information inside ordinary-looking files. Unlike encryption which makes data unreadable, steganography makes data invisible. A spy can send a photo of a landscape that carries a secret mission briefing — and anyone intercepting it sees only a landscape.

OP STEALTH combines both: your message is first AES-256-GCM encrypted, then hidden using LSB steganography. Even if someone knows to look, they still need your passphrase.

01
PIXEL ANATOMY
Every pixel has Red, Green, Blue channels — each a number 0–255. Changing the last bit (LSB) shifts a value by at most 1 — completely imperceptible to the human eye.
02
BIT ENCODING
Your message is converted to binary. Each bit is written into the LSB of a pixel channel. 3 bits per pixel (R, G, B). A 1MP image can hide ~375 KB of data.
03
MAGIC HEADER
The first 32 bits store the message length, prefixed by a magic signature "OPST" so OP STEALTH can verify and find where the message ends.
04
DOUBLE LAYER
With a passphrase, your message is AES-256-GCM encrypted first. The hidden data is ciphertext — even pixel-level forensics yield nothing without the key.
